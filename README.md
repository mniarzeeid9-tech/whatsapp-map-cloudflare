# موجة — Meshtastic Web Radio

واجهة عربية احترافية للتحكم بعقدة **Meshtastic / LoRa Mesh** من المتصفح. المشروع يعمل كواجهة ثابتة على GitHub Pages، ويتصل مباشرة بعقدة ESP32 عبر HTTP/Wi‑Fi بدون Worker أو خادم وسيط.

## الوظائف الحالية

- اتصال مباشر بعقدة Meshtastic عبر HTTP API.
- فحص الاتصال من خلال `OPTIONS /api/v1/toradio`.
- تهيئة العقدة واستقبال حالة الجهاز.
- إرسال رسائل نصية عبر Mesh إلى البث العام.
- استقبال الرسائل الواردة من العقدة وعرضها في الدردشة.
- عداد العقد المرئية.
- استقبال أحداث الموقع من الشبكة.
- حفظ سجل الدردشة محليًا في المتصفح.
- واجهة Mobile-first متجاوبة مع شريط تنقل سفلي.
- أيقونات SVG داخلية بدون اعتماد على خدمة أيقونات خارجية.
- وضع تجريبي محلي عندما لا تكون العقدة متاحة.

## الاتصال بعقدة ESP32

1. فلّش Firmware Meshtastic مناسبًا على عقدة ESP32.
2. صِل العقدة بشبكة Wi‑Fi نفسها التي يوجد عليها الهاتف أو الكمبيوتر.
3. افتح موجة واضغط **اتصل بعقدة الراديو**.
4. أدخل عنوان العقدة، مثل:

```text
meshtastic.local
```

أو عنوان IP محلي، مثل:

```text
192.168.1.42
```

5. اسمح للمتصفح بالاتصال إذا ظهرت مطالبة أمان.

## ملفات الراديو

- `radio.js`: Adapter صغير يستخدم حزم Meshtastic الرسمية ويحمّلها عند طلب الاتصال.
- `app.js`: يربط أحداث الراديو بواجهة الدردشة والعدادات.
- `index.html`: نافذة إعداد عنوان العقدة وحالة الاتصال.

## المكتبات المفتوحة المصدر

يستخدم Adapter حزم Meshtastic الرسمية عبر JSR/ESM:

- `@meshtastic/core`
- `@meshtastic/transport-http`

مصدر الحزم الرسمي: [Meshtastic Web](https://github.com/meshtastic/web)

## حدود Meshtastic المهمة

Meshtastic/LoRa مناسب للرسائل النصية الصغيرة والموقع وحالة العقد، وليس لنقل الصور أو الفيديو أو الصوت المباشر. لذلك لا يدّعي المشروع إرسال وسائط كبيرة عبر الراديو.

## التشغيل المحلي

```bash
python3 -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

## GitHub Pages

المشروع لا يحتاج Build أو npm أو Worker. اختر من إعدادات GitHub:

```text
Settings → Pages → Deploy from a branch → main → / (root)
```

## الأمان والخصوصية

واجهة HTTP في Meshtastic تفترض أن من يستطيع الوصول إلى العقدة موثوق به. لا تعرض عنوان عقدتك على الإنترنت العام بدون شبكة آمنة أو VPN. لا توجد مصادقة مستخدم داخل هذا الموقع، ولا يتم إرسال بيانات الدردشة إلى خادم موجة.

راجع [دليل إعداد الراديو](./RADIO-SETUP.md) قبل الاستخدام.
